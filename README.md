# cern-preparation-program
Nombre del programa:
CMS Open Data Workshop

Objetivo personal:
Mi objetivo principal es el intercambio cultural y de conocimientos al interactuar con investigadores y estudiantes de diversas partes del mundo. Tengo una profunda disposición por conectar mi formación en ingeniería de software con los retos de la investigación científica, para así adquirir una perspectiva global, colaborativa y multidisciplinaria.

Tecnologías o áreas que deseas fortalecer:
Deseo perfeccionar mis habilidades en C++ y en las metodologías de análisis de datos a gran escala. Busco evolucionar mi experiencia actual en el manejo de bases de datos complejas para el procesamiento de datos científicos.
